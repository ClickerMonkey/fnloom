Installing

One approval card. Nothing hidden.

  1. Pick a system

    Each listing shows its {{fns}}: what each reads, what it changes, which ones ask first, and what the system needs from you.

  2. Your admin approves

    Your hub builds that exact version, checks it, and shows the admin every {{fn}} and {{kind}} it adds before anything runs.

  3. It runs on your computer

    The system runs on a machine you choose, with only the access it declared, and anything that changes things still asks.

Publish yours

Put it in a public repository. That’s it.

There’s nothing to upload. Put your system in a public repository, under systems/<name>/ or at its root, add the repository topic {{topic}}, and the marketplace finds it, builds it, checks it and lists it at that exact version. Push a new tag to publish an update.

Don’t want to write code? Ask {{name}} to build the system with you; it writes the folder, checks it and installs it on your own hub first.

your-repo/
└─ systems/
   └─ uptime-checks/
      ├─ system.json      name, version, what it does
      ├─ server/main.ts   its fns
      ├─ client/          optional: its own screens
      └─ marketplace/     optional: icon, screenshots
