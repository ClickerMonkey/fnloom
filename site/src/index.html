How it works

A hub in the middle. Everything else plugs in.

  1. The hub keeps everything in order

    One program on your own computer holds every user, approval, memory and budget, and a record of every step it took. It all lives in one local database.

  2. Systems bring the skills

    Data, code, files, the web, schedules, MCP servers and Claude Code all come from {{systems}} that plug into the hub. They can run on any computer you own; pair one by scanning a QR code. An admin reviews each before it goes live.

  3. You pick the models

    Hundreds of cloud models through OpenRouter, OpenAI-compatible servers and Amazon Bedrock, or local models with Ollama, which it can install for you. Every {{fn}} is fitted to the model in use, so even cheaper models make fewer mistakes.

Get started

Running in a minute.

You need Node.js 22 or newer and a key for a model provider (an OpenRouter key works with hundreds of models, or point it at local Ollama models). Then:

  1. Start it. 
    $ npx {{package}}
    It starts the hub and the built-in {{systems}}, keeps its data in your home folder, and prints the address to open.
  2. Open it and sign in. The first start prints the admin sign-in. Add your model key under Settings, and invite other users when you’re ready.
  3. Use it on your phone. Settings › App › “Use it on your phone” shows a QR code and the two taps to trust the hub’s own HTTPS certificate, then install it as an app.
  4. Add more {{systems}}. 
    $ npx {{package}} system install claude
    Databases, Claude Code, APIs, MCP servers, schedules, Google Calendar, local Ollama models: every premade {{system}} is in the package, and the install guide lists what each one needs.

Questions

Good questions.

Is it self-hosted?

Yes. It runs on a computer you own and keeps everything in one local database there. Users reach it from a browser on a phone, tablet or computer, and it can send phone notifications when something needs you. Systems can run on other computers you own.

Which models does it work with?

Hundreds of models through OpenRouter, OpenAI and servers that speak its API, Amazon Bedrock, and local models through Ollama, which it can install and start for you. Claude models come through OpenRouter or Bedrock. Each chat can use a different model.

What does it cost?

{{name}} itself costs nothing to run. You pay your model provider for what you use, or nothing for local models. Spending limits can be set for the whole hub, a group, a user, a chat or a single message, and every answer shows what it cost.

Does it support more than one user?

Yes. It supports multiple users, each with their own account, and permission controls for what each can see, use and change. Anything an admin can set can also be done by asking, with approval.

Is it safe to let it touch my files?

It only works inside folders you choose. Anything that writes, deletes or runs a command waits for an approval card with a preview, unless you’ve chosen to allow it. Secret files like keys and passwords always ask and are hidden from search. Undo puts back what the last message changed and tells you plainly what it couldn’t. Systems only get the access they declared; that’s enforced by the hub, not a full operating-system sandbox.

What are systems and fns?

A {{system}} is a plug-in: a folder with a short description of what it can do and the code that does it, running on any computer you own. {{fns}} are what it brings and what {{name}} acts with: each has typed inputs, live status, and can be cancelled, paused, resumed or undone. {{kinds}} are recipes for making new {{fns}}. Plenty come built in. You can ask {{name}} to write one, and soon you’ll be able to install ones other people share from the marketplace, each after an admin approves it.

Is it open source? Is there a desktop app?

Yes. {{name}} is open source under the Apache 2.0 licence, which also promises that no contributor can later sue you over patents in the code. And it installs as an app: from Chrome, Edge or Safari on a computer, and to the Home Screen on a phone, opening in its own window with notifications. It’s the same app everywhere, not a separate download.
