Questions

Good questions.

Is it self-hosted?

Yes. It runs on a computer you own and keeps everything in one local database there. Users reach it from a browser on a phone, tablet or computer, and it can send phone notifications when something needs you. Systems can run on other computers you own.

Which models does it work with?

Hundreds of models through OpenRouter, OpenAI and servers that speak its API, Amazon Bedrock, and local models through Ollama, which it can install and start for you. Claude models come through OpenRouter or Bedrock. Each chat can use a different model.

What does it cost?

fnloom itself costs nothing to run. You pay your model provider for what you use, or nothing for local models. Spending limits can be set for the whole hub, a group, a user, a chat or a single message, and every answer shows what it cost.

Does it support more than one user?

Yes. It supports multiple users, each with their own account, and permission controls for what each can see, use and change. Anything an admin can set can also be done by asking, with approval.

Is it safe to let it touch my files?

It only works inside folders you choose. Anything that writes, deletes or runs a command waits for an approval card with a preview, unless you’ve chosen to allow it. Secret files like keys and passwords always ask and are hidden from search. Undo puts back what the last message changed and tells you plainly what it couldn’t. Systems only get the access they declared; that’s enforced by the hub, not a full operating-system sandbox.

Is it open source? Is there a desktop app?

Yes. fnloom is open source under the Apache 2.0 licence, which also promises that no contributor can later sue you over patents in the code. And it installs as an app: from Chrome, Edge or Safari on a computer, and to the Home Screen on a phone, opening in its own window with notifications. It’s the same app everywhere, not a separate download.
