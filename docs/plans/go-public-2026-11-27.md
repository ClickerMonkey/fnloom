## Decided

- **Name: fnloom.** npm package `fnloom` (unscoped), the command `fnloom`, the site's name. The GitHub repo is renamed
  `ClickerMonkey/harness` → `ClickerMonkey/fnloom` (GitHub redirects the old address). The internal workspaces keep
  their `@harness/*` names for now.
- **One npm package** holding the hub, the web app and every premade system (`@harness` isn't a scope we own).
- **Trusted publishing:** `fnloom@0.0.1` was published by hand as a placeholder; npm trusts
  `ClickerMonkey/fnloom` `.github/workflows/release.yml`, environment `npm`, for publish. A `v*` tag publishes.
- **History** (hitloop set `harness-go-public`): `.hitl/` is no longer tracked (it stays on this computer); the
  history was rewritten once before going public to replace a made-up but real-looking Gmail address in the test
  scenarios and to drop the old `.harness-test/` data (it held throwaway test keys).
- **The site** is on GitHub Pages at https://fnloom.com (clickermonkey.github.io/fnloom until the DNS is in; the name, package and repo come from
  `site/site.config.json`).
